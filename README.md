# vim
Configuration files for vim

## Setup

```sh
git clone git@github.com:rrraikman/vim.git
./vim/install.sh
```

This symlinks `.vimrc` and the Neovim config into your home directory, moving any existing files aside to `.bak`, and installs the TypeScript language server with npm if it's missing. Neovim (0.12+) installs its plugins on first launch.
